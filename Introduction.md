**Artificial Neural Network** or _ANN_ for short, is a Network Of programs that run together in defined number of loops (or _epochs_), to partially mimic a biological neuron's working, and make predictions. 

ANNs work extensively relying on calculus, and 2D Matrices. Each entry in the matrix holds one neuron and all the weights. Biases are required for neurons to think on higher domains than the origin point in a graphical representation.
